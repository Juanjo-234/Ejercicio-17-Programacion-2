# Ejercicio-17-Programacion-2
Resolución del ejercicio N°17 de programación 2.
El programa muestra como se realiza el control de la actividad en una tarjeta de credito.
Para ello verifica lo siguinte:
-Para realizar compras, controla que la tarjeta este activa y el saldo supere el monto a pagar.
-Para realizar el pago de resúmenes, controla que la tarjeta este activa y que tenga los fondo suficientes.
-Y tiene funciones parra bloquear, desbloquear y activar la tarjeta.
Al final muestra un resumen con:
Titular de la tarjeta.
Numero de tarjeta.
Saldo restante.
